## Projects

### Machine Learning and AI
- [BOT Monetary Policy Report Assistant](https://github.com/chatdanai-s/PDF-RAG-Chatbot/): Local RAG assistant for answering questions about Bank of Thailand Monetary Policy Reports.
- [Blood Cell Type Classification](https://github.com/chatdanai-s/Blood-Cell-Type-Classification): CNN image classifier. 94.53% accuracy with EfficientNetB4 on 17,092 images.
- [Traffic Volume Prediction](https://github.com/chatdanai-s/ERA5-Traffic-Volume-Prediction): Time series regression on 48,176 observations with ERA5 weather data. R² = 0.952.
- [Caries Segmentation Evaluations](https://github.com/chatdanai-s/Caries-Segmentation-Model-Evaluations): Lesion-level U-Net evaluation using Precision/Recall/and F1 metrics.

### Data Engineering and Analytics
- [NewsAPI ETL](https://github.com/chatdanai-s/NewsAPI-Supply-Chain-ETL): ETL pipeline loading supply chain disruption headlines from NewsAPI into PostgreSQL.
- [Coffee Sales Dashboard](https://github.com/chatdanai-s/Coffee-Sales-Dashboard): Streamlit BI tool with customer segmentation and actionable insights.

### Astrophysics
- [PREFACE v2](https://github.com/chatdanai-s/PREFACE-v2): **P**ipeline for **R**anking **E**xoplanets **F**or **A**tmospheric **C**haract**E**rization, refactored.
- [NATSUME](https://github.com/chatdanai-s/NATSUME): **N**ear-resonant **A**nalytic **T**TV **S**olver for **U**nknown **M**ass **E**stimates; analytic exoplanet mass calculation package.
- [TransitFetcher](https://github.com/chatdanai-s/TransitFetcher): Automated pipeline for retrieving and preprocessing space-based exoplanet transits.
